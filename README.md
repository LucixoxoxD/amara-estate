# The Amara Estate

A responsive wedding venue concept for outreach, built with HTML, CSS, and vanilla JavaScript. No dependencies or build step are required.

## Run locally

Run `npm run dev` from this directory and open http://127.0.0.1:4173.

## Features

- Responsive editorial design in oxblood, dusty rose, pale blue, and white.
- Guest count filters and detailed space dialogs.
- Photo gallery with keyboard navigation, touch swipes, and accessible dialogs.
- Sample celebration collections that prefill the enquiry form.
- Interactive day story with keyboard-accessible tabs and links to each venue space.
- Sticky navigation, active section indicators, and restrained scroll reveals respecting reduced motion.
- Three-step venue visit guide and refined form focus states.
- Required fields, date validation, enquiry review, and a text download.
- Demo planning assistant and a copyable WhatsApp enquiry draft.
- Mobile navigation and fixed visit actions; reduced-motion support.

## Demo boundaries

Amara Estate is fictional. Space names, capacities, and collections are illustrative. Photography uses remote Pexels and Unsplash images; Bodoni Moda and Manrope are loaded from Google Fonts, with system fallbacks. No enquiries are transmitted, no reservations are made, and no personal details are stored. The form retains details only in memory while the page is open. There is no connected WhatsApp number, payment system, backend, or booking calendar.

## Adapt for a real venue

Replace the brand, photography, location, capacities, collections, and vendor policies with verified venue details. Connect the enquiry form to the chosen CRM or backend and add the venue’s confirmed WhatsApp number and privacy policy before launch.

## Files

`dist/index.html` contains the page content; `dist/styles.css` contains the responsive design; `dist/app.js` controls interactions. `server.cjs` is a development-only static server. The deployable site consists of `dist/` and `.openai/hosting.json`.

## Design references

The redesign draws on the generous spacing and varied image scale of [Kin House](https://kinhouse.co.uk/), the navigation and narrative structure of [The Calile](https://thecalilehotel.com/), and the property-specific identity of [The Johri](https://www.thejohrijaipur.com/). The palette, Amara wordmark, layout, and page copy are original to this demo.

The hero is a free stock image by The Visionary Vows: https://www.pexels.com/photo/luxurious-outdoor-indian-wedding-venue-setup-33417234/. Supporting detail image: https://www.pexels.com/photo/wedding-venue-decoration-12412180/.
